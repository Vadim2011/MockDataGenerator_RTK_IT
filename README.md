# MockDataGenerator_RTK_IT

## Учебный проект
**Система для генерации случайных тестовых данных**
! не использовать в работе
Сервис генерирует случайные данные, на основании заданных пользователем параметров.
Сохраняет на сервере результат, передает результат пользователю, хранит историю
запросов пользователя в БД и ФХ

## Используемые технологии:
git, html, css, js, sql (db postgres), python (flask)
развертывание на домашнем сервере, доключение домена
ИИ - проверка, улучшение, написание функций для Python
